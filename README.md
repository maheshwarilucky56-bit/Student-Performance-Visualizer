# Student Performance Visualizer 📊

A Python Data Science project for analyzing and visualizing student performance.

## Features

- Student performance analysis
- Average marks calculation
- Average study hours
- Attendance analysis
- Top student identification
- Marks comparison
- Study hours vs marks visualization
- Attendance vs marks visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## How to Run

Install libraries:

pip install pandas numpy matplotlib

Run the project:

python app.py
